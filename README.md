
# Minecraft Mod Auto Translator (AI Powered)

Minecraft の Mod ファイル（`.jar`）から言語ファイル（`en_us.json`）を抽出し、**Google 翻訳** または **生成 AI（Gemini / Local LLM）** を用いて、高品質な日本語化リソースパックを全自動で生成するツールじゃ。

Mod ファイル本体（`.jar`）を書き換えることはなく「読み取り専用」で扱うため、 **Mod が破損する心配は一切ない** 。安全に日本語化を楽しめるぞ。

## 🚀 特徴

### 1. 選べる翻訳エンジン

* **Google 翻訳** : 完全無料、API キー不要。手軽に翻訳したい場合に最適。
* **Gemini AI (推奨)** : Google の高性能 AI。文脈を理解した自然な翻訳が可能（要 API キー）。
* **スマートモデル選択** : `gemini-2.5-flash-lite-preview` や `gemma-3` などの最新・高速モデルを自動で優先使用。
* **Lite 限定モード** : 高速かつ低コストな「Lite」モデルのみを使用するモードを搭載。
* **自動フォールバック** : API 制限（429 エラー）が発生しても、自動で次のモデルや待機処理に切り替わり、止まらずに翻訳を継続する。
* **Local AI (Ollama / LM Studio)** : PC 内のローカル LLM を使用。完全無料・無制限だが、PC スペックが必要。

### 2. シェーダーパック翻訳対応 (New!)

* **`.lang` ファイル対応** : Mod の `.json` だけでなく、シェーダーパック特有の `.lang` ファイル（`key=value` 形式）も翻訳可能。
* **自動モード切替** : フォルダ名に `shader` が含まれている場合、自動的に「シェーダー翻訳モード」に切り替わり、適切なフォルダ構造で出力する。

### 3. 賢いエラー対策 & 自動修復

* **自動クリーニング** : 翻訳結果に「Error 504」や「HTTP 429」などのエラーメッセージが混入しても、ツール起動時に**自動検知して削除**する。
* **自己修復** : すでに誤った翻訳で出力されてしまった `ja_jp.json` や `.lang` ファイルも、ツールを再実行するだけで自動的に修正・再翻訳される。
* **最終防衛ライン** : ファイル保存直前にもチェックを行い、エラー文字列が含まれている場合は**原文（英語）**に戻して保存する。

### 4. プロジェクト管理 & 利便性

* **プロジェクト別管理** : 翻訳キャッシュ（`trans_cache.json`）と進捗ログ（`progress_log.json`）を出力リソースパックのフォルダ内に保存。複数の Mod パックを並行して翻訳してもデータが混ざらない。
* **中断・再開** : いつでも中断でき、同じ出力先を指定すれば続きから再開できる。
* **ドラッグ＆ドロップ対応** : フォルダパスの入力は、ウィンドウにフォルダをドラッグ＆ドロップするだけで OK。

## 💻 必要要件

1. **Windows OS** （推奨）
2. **Python 3.x**
   * インストール時、 **「Add Python to PATH」に必ずチェックを入れること** 。
3. **インターネット接続** （AI API 使用時）
4. **(Gemini モードのみ)** : Gemini API キー。

* [Google AI Studio](https://aistudio.google.com/app/apikey "null") から無料で取得可能。

1. **(Local AI モードのみ)** : [Ollama](https://ollama.com/ "null") または [LM Studio](https://lmstudio.ai/ "null")。

## 📖 使い方（推奨手順）

基本的には、付属の `start.bat` をダブルクリックして対話形式で進めるのが一番簡単じゃ。

### 手順 1: 起動

start.bat をダブルクリックする。

初回起動時は、必要なライブラリ（deep-translator 等）が自動でインストールされるので、少し待つのじゃ。

### 手順 2: 翻訳エンジンの選択

メニューが表示されるので、数字キーを押して選択する。

* **[1] Google Translate** :
* API キー不要。精度はそこそこだが、一番手軽。
* **[2] Gemini AI** :
* **API キー**の入力を求められるので、コピー＆ペーストする（右クリックで貼り付け）。
* その後、**「Lite 限定モード (Lite-Only Mode)」** を使うか聞かれる。
  * **[Y]** : `gemini-2.5-flash-lite` などの軽量モデルのみを使用する。制限にかかっても Pro モデルには逃げず、Lite の回復を待つ（トークン節約・高速化に最適）。
  * **[N]** : Lite が使えない場合、Flash や Pro モデルなども含めて総力戦で翻訳する。
* **[3] LM Studio / Ollama** :
* ローカル LLM を使用する場合。
* **LM Studio の場合** : 事前に LM Studio を起動し、**「Developer」タブ（サーバーアイコン）** から **「Start Server」** を押しておくこと（ポート `1234`）。

### 手順 3: フォルダの指定

1. **「翻訳したい Mod または シェーダーパック が入っているフォルダ」** をウィンドウにドラッグ＆ドロップして Enter。
2. **「出力するリソースパックの場所（名前）」** を入力。
   * 名前だけ（例: `MyPack`）入力すると、ツールと同じ場所に作成される。
   * フルパス（例: `C:\Users\Me\Desktop\MyPack`）や、既存フォルダをドラッグ＆ドロップしても OK。
   * **重要** : 以前作成したフォルダを指定すると、**続きから翻訳を再開** できる。エラー修正もこの時に行われる。

### 手順 4: 翻訳開始

あとは待つだけじゃ。進捗バーが表示され、翻訳がガシガシ進んでいくぞ。

生成されたフォルダを Minecraft の resourcepacks（シェーダーの場合は shaderpacks 内の対象 zip を解凍して上書き、またはそのまま配置）に入れて適用せよ。

## 🔧 上級者向け（コマンドライン実行）

バッチファイルを使わず、コマンドラインから直接 Python スクリプトを実行する場合の引数一覧じゃ。

細かい挙動を制御したい場合に使うがよい。

### ヘルプの表示

```
python mod_translator.py -h


```

### 利用可能な Gemini モデル一覧の確認

引数なしで実行すると、API キーを入力して現在利用可能なモデル一覧を表示できる。

```
python mod_translator.py


```

### 実行例

**1. Gemini API (Lite 限定モード) で実行**

```
python mod_translator.py -i "C:\Mods" -o "MyPack" --engine gemini --key "AIza..." --lite-only


```

2. シェーダーパックの翻訳

フォルダ名に shader を含めると自動でモードが切り替わる。

```
python mod_translator.py -i "C:\ShaderPacks" -o "MyShaderPack" --engine gemini --key "AIza..."


```

### 引数一覧

| **引数**  | **短縮** | **説明**                                               | **デフォルト値** |
| --------------- | -------------- | ------------------------------------------------------------ | ---------------------- |
| `--input`     | `-i`         | Mod/Shader が入っているフォルダパス。                        | -                      |
| `--output`    | `-o`         | 生成するリソースパックの出力先パス。                         | `Output_Pack`        |
| `--format`    | `-f`         | `pack.mcmeta`のバージョン指定。`-1`なら自動検知。        | `-1`(自動)           |
| `--engine`    | -              | 翻訳エンジン (`google`,`gemini`,`ollama`,`lmstudio`) | `google`             |
| `--key`       | -              | Gemini API キー（Gemini モード時は必須）                     | -                      |
| `--model`     | -              | Ollama で使用するモデル名                                    | `gemma2:9b`          |
| `--priority`  | -              | Gemini 使用時のモデル優先順位（カンマ区切り）                | (推奨設定)             |
| `--lite-only` | -              | 名前に `lite`を含むモデルのみを使用するフラグ              | 無効                   |
| `--force`     | -              | 既存の日本語訳があっても強制的に上書き翻訳する               | 無効                   |
| `--reset`     | -              | 指定した出力パック内の進捗ログを削除し、最初からやり直す     | 無効                   |
| `--help`      | `-h`         | ヘルプを表示する                                             | -                      |

## ⚠️ 注意事項

1. **API 制限 (429 エラー)** :

* Gemini API (Free) にはレート制限がある。本ツールは制限を検知すると自動で待機したり、別のモデルに切り替えたりするが、一時的に処理が遅くなることがある。

1. **翻訳精度** :

* AI 翻訳は強力じゃが完璧ではない。「Chest」を「胸」と訳したり、JSON の記号を壊すこともある。
* **エラー文字列 (Error 504 など) が混入した場合** : ツールを**再実行**するだけで、自動的に検知・削除され、正しい翻訳に修正される。

1. **バックアップ** :

* Mod ファイル自体は変更しないので安全じゃが、生成されたリソースパックを配布する際などは内容を確認することを勧める。
