# **Minecraft Mod Auto Translator**

Minecraft の Mod ファイル（.jar）から言語ファイル（en_us.json）を抽出し、Google 翻訳を用いて日本語化リソースパックを自動生成するツールじゃ。

**Mod ファイル本体（.jar）を書き換えることはない（読み取り専用）** ため、安全に利用できるのが特徴じゃの。

## **特徴**

- **自動バージョン検知**: Mod フォルダ内の pack.mcmeta をスキャンし、最適な pack_format を自動で設定する。バージョンをいちいち調べる必要はないぞ。
- **安全設計**: Mod の Jar ファイルは「読み取り専用」で開くため、Mod が破損する心配がない。
- **全自動セットアップ**: start.bat を実行するだけで、Python 仮想環境（venv）の構築と依存ライブラリのインストールを自動で行う。
- **翻訳キャッシュ機能**: 一度翻訳したテキストは trans_cache.json に保存され、次回以降は API を使わずに高速化される。
- **中断・再開機能**: 処理済みの Mod は progress_log.json に記録され、途中から再開が可能じゃ。
- **差分翻訳**: 既に日本語ファイル（ja_jp.json）が存在する場合は、未翻訳のキーのみを翻訳してマージする。

## **必要要件**

- **Python 3.x**: インストール時に「Add Python to PATH」にチェックを入れていること。
- インターネット接続（Google 翻訳 API を使用するため）

## **使い方（推奨）**

基本的には start.bat をダブルクリックするだけでよいぞ。

1. start.bat を実行する。
2. 初回起動時は必要なライブラリが自動でインストールされるので待つのじゃ。
3. **「翻訳したい Mod が入っているフォルダのパス」** を求められるので、フォルダをドラッグ＆ドロップするかパスを入力して Enter を押す。
4. **「出力するリソースパックの名前」** を入力する（空欄なら Generated_Pack になる）。
5. ツールが Mod を解析し、最適なバージョンを検知してから翻訳を開始する。
6. 完了すると指定した名前のフォルダ（リソースパック）が生成されるので、それを Minecraft の resourcepacks フォルダに入れて適用せよ。

## **使い方（コマンドライン / 上級者向け）**

バッチファイルを使わず、仮想環境から直接 Python スクリプトを実行する場合の引数は以下の通りじゃ。

### ヘルプの表示

```bash
python mod_translator.py -h
```

```bash
### 基本的な実行（バージョン自動検知）
python mod_translator.py -i "C:\Path\To\Mods" -o "My_Resource_Pack"
```

```bash
### バージョンを手動指定する場合（例: 1.20.x 用なら 15）
python mod_translator.py -i "C:\Path\To\Mods" -f 15
```

```bash
### 強制翻訳モード（既存の訳を無視）
python mod_translator.py -i "C:\Path\To\Mods" --force
```

### **引数一覧**

| 引数      | 短縮 | 説明                                               | デフォルト値   |
| :-------- | :--- | :------------------------------------------------- | :------------- |
| \--input  | \-i  | Mod が入っているフォルダパス（必須）               | \-             |
| \--output | \-o  | 生成するリソースパックの出力先フォルダ名           | Output_Pack    |
| \--format | \-f  | pack.mcmeta のバージョン指定。\-1 なら自動検知。   | \-1 (自動検知) |
| \--force  | \-   | 既存の日本語訳があっても強制的に上書き翻訳する     | 無効           |
| \--reset  | \-   | 進捗ログを削除し、最初から全ファイルをスキャンする | 無効           |
| \--help   | \-h  | ヘルプを表示する                                   | \-             |

## **生成されるファイルについて**

- **trans_cache.json**: 翻訳結果のキャッシュ。削除すると次回実行時に API 通信が再度発生する。
- **progress_log.json**: 処理済み Mod のリスト。削除すると最初からスキャンし直す。
- **venv/**: Python の仮想環境フォルダ。

## **注意事項**

1. **Pack Format の検知**: フォルダ内の Mod をいくつかサンプリングして、最も多く使われているバージョン（最頻値）を採用する仕組みじゃ。もし検知できなかった場合はデフォルト値（34 \= 1.21.x 想定）が使われる。
2. **API 制限**: 短時間に大量の翻訳を行うと、Google 翻訳側から一時的にブロックされる可能性がある。スクリプト内で待機時間を設けておるが、数百個の Mod を一気にやる時は気をつけるのじゃ。
3. **機械翻訳**: 精度は Google 翻訳頼みじゃ。固有名詞などが変な訳になっても文句は言うでないぞ。
